# Slide archetypes (26)

Evidence: 8 PPTX decks reviewed by hand (~250 slides) + 71 PDF decks (~2,070 slides) classified by 5 parallel vision passes
over contact sheets (`render/pdfsheets/`). Counts are approximate (±10 %, eyeballed from thumbnails), summed over the PDF pass.
All 26 are **built** (`examples/catalog.json` → `out/catalog.pptx`). Spec fields/limits: `schemas/archetypes.schema.json` (generated by `tools/gen_schema.py`).
Types 1–25 are the classified set; type 26 (`composite`) is the dense multi-element slide added later, see below.

Narrative rule in every content slide: **action title (insight as a sentence) → evidence → so-what bar → source.**

## Composite (type 26): dense multi-element slide

One slide, 1–6 panels in a fixed grid, joined by links. Code: `slidegen/composite.py` (+ `slidegen/charts.py`). Example: `examples/composite_orbital.pt.json`, plus its catalog entry.

**Layouts** (`layout`). Panels fill the slots in reading order, so the panel count must equal the slot count.
| `layout` | Slots | Shape |
|---|---|---|
| `1` | 1 | single body |
| `2col` | 2 | side by side (`weights`) |
| `3col` | 3 | three columns |
| `T\|B` | 2 | top / bottom (`weights`) |
| `L\|R2` | 3 | left full height, right top / bottom (`right_weights`) |
| `L2\|R` | 3 | left top / bottom, right full height |
| `2x2` | 4 | 2 × 2 grid |
| `4col` | 4 | four columns (`weights`, 4 values) |
| `2x3` | 6 | 2 rows × 3 columns, reading order row by row (`weights` = the 3 column widths) |
| `L\|R3` | 4 | left full height, right 3 stacked (`weights` left/right, `right_weights` 3 heights) |
| `T\|B3` | 4 | top full width, bottom 3 side by side (`weights` top/bottom, `right_weights` 3 widths) |
| `T2\|B3` | 5 | top 2 side by side, bottom 3 (added so that 5 items have a 5-panel layout; same weights as `T\|B3`) |
| `cols` | any | free columns: spec `cols` = `[{"w": width, "rows": [row heights], "title", "intro", "intro_size", "span"}]`; slots column by column, top to bottom. A column `title` (spanning the column, on the slide header style) and `intro` text sit above its rows; `span: 2` carries one header over two columns (s01, s02, s04, s05, s06 of the audit). Spec `band` `{h, title, title_badge}`: the FIRST panel runs across the full width on top (an exhibit that needs width, or a KPI strip at h ~0.2), the columns fill the rest below a dashed line. Spec `section_style` `label` / `centred_rule` / `bar` / `rule`: look of the column (section) headers only |

Gutters, dividers (`dividers`/`divider`), `frame`, the fill rule, the density check and the arrow adjacency rule (side by side or stacked, never diagonal) are the same for every layout.

**Panel kinds** (`panels[].kind`; required fields in brackets).
| `kind` | Fields | Notes |
|---|---|---|
| `chart` | `chart` {kind, categories, series} | chart kinds: column, stacked, stacked100, bar, line, pie, doughnut, waterfall. Option `backing` |
| `table` | `columns` (2–6), `rows` | row = list of cells (text, a list of short lines, `{bars}` mini-bars, `{icon, text, pos}` icon cell, or `{pill, color}` = small rounded filled tag, `color` a theme key or hex); `{group}` = group row, `{total}` = total row |
| `bullets` | `items` (1–6) | plain sentences, `**bold**` lead-ins; options `backing`, `icons` (one Lucide name per item, `""` = none: icon rows instead of bullets) |
| `cards` | `items` (2–5 of {title, text, icon?}) | options `numbered`, `card_fill`; an item `icon` replaces its number badge |
| `kpis` | `items` (1–4 of {value, label, icon?}) | option `backing` |
| `map_br` | `values` (UF → number, ≥ 3) | Brazil tile map; `highlight`, `number_format` |
| `process` | `steps` (2–5 of {title, text}) | |
| `flow` | `nodes` (2–15 of {id, text, parent?, style?, op?}) | boxes joined by connectors; `parent` = the node a box feeds, the one node without parent is the result (bottom, or right with `direction: "lr"`); `style` grey / outline / fill / plain; `op` (+ × = −) = operator circle where that node's inputs join. Drawn by `diagram_slides.draw_tree`, the engine of `flowchart` / `issue_tree` |
| `matrix` | `x_label`, `y_label`, `quadrants` (4), `items` (2–8 of {label, x, y, size}) | x, y in 0–10 |

**Composite elements** (flow, icons, pills, phases, callouts; example `examples/composite_elements.pt.json`; icon cells, side labels, connectors, scale bar and notes: `examples/composite_elements2.pt.json`).
- `flow`: `{"kind": "flow", "direction": "lr", "nodes": [{"id": "tot", "text": "Custo total", "style": "fill", "op": "+"}, {"id": "opex", "text": "OPEX", "style": "outline", "parent": "tot"}, {"id": "capex", "text": "CAPEX", "style": "fill", "parent": "tot"}]}`. Needs about 0.6 in per leaf (`lr`) or 0.5 in per level + 0.55 in per connector (`td`).
- Icons (Lucide names, `find_icons`): `{"kind": "kpis", "icon_style": "disc", "items": [{"value": "R$ 2 mi", "label": "OPEX", "icon": "wallet"}]}`; same `icon` on cards items; bullets panel uses `"icons": ["rocket", ""]`. `icon_style` `disc` (default: white icon on a brand disc) or `line` (plain brand-colour icon). Icons are the only pictures.
- Pill cells: `{"pill": "Dado público", "color": "primary"}` in a table row (colour = theme key `primary` / `dark` / `accent` / `pale`, or hex; text turns white on dark fills). A legend row under the table: panel option `"pill_legend": {"label": "Origem:", "pills": [{"pill": "Benchmark", "color": "C0701F"}]}` (reserves 0.34 in, sits above `footnotes`).
- Chart `phases` (column, stacked, stacked100, line, waterfall): `"phases": [{"start": 0, "label": "1"}, {"start": 3, "label": "2"}]`: dashed divider before each later phase, label above its span (extra 0.3 in headroom; not with `legend_pos` top).
- Icon cell (table): `{"icon": "fuel", "text": "Etanol hidratado", "pos": "top"}`: Lucide icon above the text (`pos` `top`, default) or at its left (`left`), `icon_style` of the panel; row height grows by about 0.5 in. Use `align` `c` for the usual centred look.
- `side_label` (any panel): `"side_label": "ACTIVITY"` (+ `"side_fill": "4D4D4D"`, default brand colour) = narrow strip at the panel's left edge, text rotated 270 degrees, content shifted right by 0.34 in. List form for a table or cards panel, strips aligned to rows/items: `"side_label": [{"text": "CARROS", "rows": [0, 0]}, {"text": "BIOCOMBUSTÍVEIS", "rows": [0, 1], "level": 1}]` (`rows` = first and last body row / card item, `fill` theme key, hex or `none`, `level` 1 = second strip right of the first, pale fill).
- `scale` (any panel; reserves 0.75 in at the bottom of the panel, above pill legend and footnotes): `"scale": {"colors": ["D93025", "F5D90A", "3DAE2B"], "left": "Consolidated", "right": "Fragmented", "markers": [{"at": 0.0}, {"at": 0.7, "label": "Wine Market"}], "frame": true}`: bar with a native gradient fill (2-4 stops, default green-yellow-red), end labels under it, 1-3 arrow markers at `at` 0..1 with optional label, `frame` = dashed brand box. Keep marker labels at least 1.3 in apart.
- Chart `callouts` (pie, doughnut): `"callouts": true`: bold name + value (`percent: true` = share) outside the ring with leader lines, no legend; use a panel at least about 4.5 in wide.

All kinds take `id` (required, unique, used by links), `title`, `tag`, `panel` (`grey`/`none`), `callout` {lead, text} and `footnotes` (1–3). All kinds except `bullets`, `cards` and `flow` also take `bullets` (flow panels use `callout` instead) (1–4) under the element. Per-kind layout options (widths, row heights, alignment, fonts) are listed in `tools/gen_schema.py` (`EXTRAS`, `PANELS`).

**Emphasis shapes** (all optional, native shapes, nothing drawn unless used; example `examples/composite_emphasis.pt.json`). The archive (740 content slides) contrasts and emphasises with small text-less shapes: a rect on 89 % of slides, ellipse 54 %, chevron 34 %, triangle 12 %, pentagon arrow (homePlate) 6 %. Fill tokens: `grey` (F2F2F2), `grey_dark` (D9D9D9), `grey_mid` (A6A6A6), a theme key (`pale`, `primary`, `dark`) or a hex.
- `emphasis` `backdrop` (archive: grey/pale box behind a key panel, row or "so-what" band, ~36 % of slides, big panel backdrops 20 %): `{"kind": "backdrop", "panels": ["c"], "y": [0.7, 1], "fill": "grey", "outline": "none"}`. `y` (optional) limits the box to a vertical band of the panels' union; `outline` `none` / `dashed` / `solid`. Drawn under all content. For plain per-panel grey use the panel option `panel: "grey"` or `frame`.
- `emphasis` `pointer` (triangle pointer or wedge from one block to the next, ~12 % of slides; block arrows between two states are rare, under 1 %): `{"kind": "pointer", "from": "a", "to": "b", "shape": "triangle"}`. Sits in the gutter between neighbouring slots (side by side or stacked, never diagonal), default fill `grey_mid`; `shape` `block` draws a block arrow. Use it where `links` `arrow` (red disc chevron) would be too loud.
- `emphasis` `accent_bar` (thin vertical bar beside a block of text, ~21 % of slides): `{"kind": "accent_bar", "panel": "k", "fill": "primary"}`; a 0.05 in bar in the gutter left of the panel, from under its title to the slot bottom.
- Panel option `title_shape` (archive: pentagon / chevron step headers, ~5 % and 34 %): `"title_shape": "pentagon"` (or `"chevron"`) draws the panel title as an arrow banner in `header_fill` / brand colour; needs `title`. Good for sequential panels (step 1 > step 2 > step 3).
- kpis item `delta` (up / down triangle after the figure, archive delta markers): `{"value": "18%", "label": "Margem", "delta": "up", "delta_color": "grey"}`; default 4D4D4D. Side-by-side kpis put it right after the figure, stacked kpis in one column at the right edge of the figure column.
- Not added: text-less discs as bullets/markers (use `icons` or `numbered` cards) and the red disc chevron (already `links` `arrow`).


| `kind` | Fields | Effect |
|---|---|---|
| `arrow` | `from`, `to` (panel ids); `anchor: centre` | thin arrow between neighbouring panels |
| `bracket` | `from` (2–3 ids), `to`, `label` | merges several panels into one |
| `highlight` | `panel`, `categories` (1–4), `label` | boxes chart categories; the other bars go grey |
| `callout` | `panel`, `category`, `text` | note on one chart category |
| `xref` | `panel` (list), `to` (chart panel), `pairs` [[item index, category index]] | numbered badges linking list items to chart categories |
| `cagr` | `panel` (chart), `from`, `to`, `label`, `style` `pill` / `diagonal` | growth bracket between two categories |
| `connector` | `from` (chart panel), `category`, `to` (table or cards panel), `row`, `via` (0.05-0.95, default 0.5) | elbow arrow from a bar (dot on it; waterfall bars: middle of the floating bar) to a table row / card, ending at the target panel's left edge (put a `side_label` there). Column, stacked, waterfall and bar charts. Example `{"kind": "connector", "from": "c", "category": 1, "to": "t", "row": 0}`; vary `via` so vertical legs do not overlap |
| `note` | `panel`, `text` (max 90), `at` (`top-right` default, `top-left`, `bottom-right`, `bottom-left`, or a chart category index), `target` (category) | small free-floating dotted-outline box (9 pt) in a corner of the panel's element area, or above bar `at`; a thin arrow leads to the bar when `at` is an index or `target` is given. Example `{"kind": "note", "panel": "s", "text": "Typical CAGR of a promising market", "at": 3}`. Corner boxes sit on top of the element: keep clear of chart titles / bars |

**Main options** (top level; the full list is in `tools/gen_schema.py`).
| Option | What it does |
|---|---|
| `layout`, `panels`, `source`, `headline` | required; `source_label` replaces "Fonte" in the footer (no trailing colon — the code adds it automatically; write "Fonte", not "Fonte:") |
| `takeaway` | so-what bar at the bottom |
| `tag` + `tag_style` | `tag_style: "plain"`: small grey caps kicker top-left above the title (e.g. "Anexos", "Apêndice"); `box` = outlined stamp top-right |
| `title_size` | action-title size in pt for this slide (14-40); the build fails if the headline does not fit the title area at that size (big titles must be short) |
| `logo` | one logo or a list of up to 3 `{file, position, height}`; logos with the same position sit side by side; `height` up to 0.9 in |
| panel or `cols` column `title_badge` | numbered circle in the brand colour left of the panel / column title (archive section numbers 1, 2, ...) |
| `header_style` (`dotline` / `bar`), `header_fill`, `header_text`, `header_caps`, `header_bold`, `header_italic` | panel header look for this slide, overriding the theme |
| `frame` | `{panels, style: dashed / solid / none, title_outside}`: outline around a group of panels |
| `emphasis` | list of `backdrop` / `pointer` / `accent_bar` shapes, see "Emphasis shapes" |
| `dividers`, `divider` | dashed line between stacked slots / at the column gutter; in `cols`, `divider` draws a line at every column gutter and `dividers: true` one between the stacked rows of each column (spec only, not the theme token) |
| `chart_font` | text size (pt) of all chart labels on the slide, overriding the theme |
| table `pill_size`, flow `node_size` | pill text pt (chip scales), flow node text pt |

Colours: hex or `grey` / `grey_dark` / `grey_mid` / `pale` / `primary` / `dark`. Example `examples/composite_tables.pt.json` |
| table cell `{"text", "fill", "bold", "box"}` | one styled cell: own fill, bold, or `box` = dashed outline around it (highlight one figure). Pills, cell boxes and chevrons sit on the nominal row height: a row that wraps taller shifts them, so keep those rows to one line or set `row_h` |

| `table_header`, `title_bold`, `title_rule`, `subtitle_italic`, `source_italic`, `corners` | overrides of the theme tokens (see `docs/styles.md`) |
| `accent_words`, `accent_bold` | headline phrases drawn in the brand colour |
| `group_fill`, `group_color` | table group-row fill and text colour |
| `page_number`, `page_number_font`, `page_number_size`, `page_number_bold` | footer page number |

**Rich text** (any text field: headline, bullets, cells, callouts, cards).
| Markup | Renders as |
|---|---|
| `**text**` | bold |
| `==text==` | bold, in the brand-coloured text (`text_primary`) on bullets; table cells use their own accent |
| `//text//` | italic |

Markup characters are not counted by the length estimate for `**` and `==`; `//` still counts.

**Scatter and bubble charts** (`chart.kind` `scatter` | `bubble`, panel kind `chart`). Native XY chart (editable data). Data: `points: [{x, y, label?, size?}]` (one series) or `series: [{name, points}]`; bubble needs `size` on every point. Options: `x_title`, `y_title`, `x_format`, `y_format`, `x_min`/`x_max`/`y_min`/`y_max` (default: padded round numbers), `highlight: [point indexes]` (primary, others grey; single series), `labels` (default true: the point `label` written next to the point), `bubble_scale`, `gridlines`, and `quadrants: {"x": value|"mean", "y": value|"mean", "labels": [top-left, top-right, bottom-left, bottom-right]}` (thin dashed grey lines + light corner labels, native shapes over a fixed plot area). Value axes are always visible. The `highlight`, `callout`, `xref` and `cagr` links do not apply to XY charts. Example: `examples/composite_scatter.pt.json`; 2 × 3 example: `examples/composite_2x3.pt.json`. `tools/compose.py` suggests a scatter for a `correlation` item with `dimensions` >= 2 (bubble with 3) and >= 4 points. Not available in the standalone chart archetypes (`chart_takeaway`, `multi_chart`).

**Logo** (any slide with a footer, spec field `logo`, or theme token `logo`, see `docs/styles.md`): `{"file": path, "position": "footer-right" | "footer-left" | "top-right", "height": inches (0.15–0.5, default 0.3)}`. Aspect ratio kept; the source line, page number, footer tag and (top-right) the title shift clear of it. Missing file = build error. Example: `examples/composite_logo.pt.json` (placeholder `examples/data/logo_placeholder.png`).

**Density warning.** After a build, a composite slide with sparse content adds a non-fatal warning to the build's `warnings` list: more than 2 of the 24 cells in the 4 × 6 body grid are under 15 % covered, or total coverage is under 0.55. Nothing is blocked; add panels or content, or change the layout. Errors (not warnings) come from `composite.check`: layout and panel-count mismatch, unknown panel ids in `frame` or `links`, and a link kind on the wrong panel type.

## Cross-cutting features (patterns, not slide types)
- **Section tracker** (`tracker`: sections + active) — footer stepper seen on most finalist decks.
- **Gradual reveal / build sequence** (~120 slides): `active` on `icon_columns`, `process_steps`, `agenda_divider`.
  The AI layer produces N copies with `active = 0..N-1`.
- **Story colouring**: `highlight` (one series grey, focal bars in primary) — Bain "Chart it up" and chart add-in training rule.
- **Callout bubble** (`chart.callout`, e.g. "CAGR +9%").
- **Stamp** (`tag`: ILUSTRATIVO / PRELIMINAR) — Bain rule for non-final data.
- **Bottom rule** above source/page number (`footer_rule`, on by default) and optional rule under the title (`title_rule`).

## Seen but not given a type (decide later)
Porter / radar slides (~6), pyramid diagrams, Marimekko, bubble/scatter with regression (Bain chart list), sensitivity heat-map grids
(valuation decks), code-screenshot appendices (covered by `exhibit_annotated` with the user's image).

## Copy rules (enforced by schema limits + the skill)
- Headline: full sentence with a verb and a number, ≤ 190 chars (≤ 2 lines at 20 pt). Reading the titles in order tells the story.
- One message per chart; the highlighted element is the one the title is about.
- Every data slide has a source; never invent one ("Dados ilustrativos" when there is none).
- Bullets: bold lead-in + one claim. Takeaway: one sentence, the implication.
