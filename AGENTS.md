# Slide generator: instructions for coding agents

Python (python-pptx) tool that builds ONE finished, native, editable consulting slide from a JSON spec, in the style of a case-competition archive. Windows; Python is `py -3`.

Read before changing anything: `docs/rulings.md` (the user's decisions, which win over the code), `docs/architecture.md` (map of the code), `docs/archetypes.md` (spec reference; `composite` is the main archetype).

## Layout
- `slidegen/`: rendering. `composite.py` (multi-panel slides), `charts.py` (native charts), `core.py` (text, shapes, footer), `themes.json` (styles as tokens).
- `build.py`: CLI + validation. `schemas/archetypes.schema.json` is GENERATED by `tools/gen_schema.py`; edit the generator, then run `py -3 -I tools/gen_schema.py`.
- `mcp_server.py`: MCP server (slide tools). `.claude/skills/slide/SKILL.md`: the slide-making workflow (Claude Code loads it as the `/slide` skill; `desktop/slide` is the Claude Desktop version).
- `tools/`: `compose.py` (composition recommender), `grammar.py` (archive slide grammar from vision labels -> `brain/30-patterns/`), `retrieve.py` + `rank.py` (nearest examples, best-of-3), `layout_metrics.py`, `ab_judge.py` (blind A/B), `preview.ps1` (render with real PowerPoint).
- `exemplars/`: approved example slides (spec + png). `examples/`: example specs. `analysis/`: archive statistics (`grammar.json`, `layout_stats.json`, anonymised `elements*.jsonl`). `docs/gaps.md`: ranked tool gaps.
- Local only, never in git: `archive/` (source decks), `out/`, `render/`, and `private/` (real deck/team names, exemplars rebuilt from other teams' slides, audits). The repo must not leak other teams' material: after regenerating archive-derived files (`mine_elements`, `merge_labels`, `grammar.py`, `summarize_elements`), run `py -3 -I tools/anonymize.py` before committing.

## Commands (run from the project root)
- Build: `py -3 build.py spec.json -o out/name.pptx [--theme bain_red]`; styles: `py -3 build.py --styles`
- Render: `powershell -NoProfile -File tools\preview.ps1 out\name.pptx` (writes out\name.png; look at it)
- Tests (all must exit 0 before you commit):
  `py -3 tools/test_build.py`, `py -3 tools/check_examples.py`, `py -3 -I tools/test_compose.py`, `py -3 -I tools/test_mcp.py`, `py -3 -I tools/test_metrics_ab.py`, `py -3 -I tools/test_retrieve_rank.py`

## Rules
- Smallest working change; reuse helpers that already exist; no new dependencies.
- New options must not change existing renders unless the change is the point; re-render `examples/composite_orbital.pt.json` after touching layout or chart code and look at it.
- Never edit `.claude/settings.local.json`, secrets or API keys; never commit `archive/` or `private/`.
- Work on a git branch, commit small steps with clear messages; `main` is the stable line and the only branch pushed to GitHub (never push tags or the local `full-history-*` history).
